# container_configs/EXAMPLE.txt
#
# Three sections are supported. All are optional.
#
# [addons]
#   Each line is a directory (relative to project root).
#   Must be under odoo/custom/ or odoo/extra-addons/. Every immediate subdirectory becomes a module
#   in this project's instance environment (odoo/auto/instances/<project>/addons/),
#   which is the only custom addons dir that instance sees. Dot-prefixed dirs
#   (.git, etc.) are skipped. Later entries override earlier ones when names
#   clash, so list shared repos first and project-specific overrides last.
#
# [setup]
#   Each line is a path to a shell script (relative to project root).
#   Scripts live in container_configs/ alongside this file.
#   They are piped to bash as root inside the container before pip install runs —
#   use them to install system-level build dependencies (apt-get, etc.).
#   See EXAMPLE.sh for a template.
#
# [requirements]
#   Each line is a path to a requirements.txt (relative to project root).
#   Must be under odoo/custom/ or odoo/extra-addons/ (the bind-mounted volume).
#   `workon` / `start -p` runs `pip install -r` for each one.
#
# Usage:
#   python3 odoo-cli.py workon EXAMPLE
#   python3 odoo-cli.py start -p EXAMPLE -d mydb
